Solver convergence bench

Runs the real solver for a fixed number of steps against a stationary body and records the largest distance any particle moved between steps. Colliders never move here, so anything that fails to settle is intrinsic to the solve rather than driven by a moving body.

Needs a GPU. Headless has no WebGPU device on this machine, so this page is the only way to obtain the curve — run it on the current checkout, then on any other commit, and compare.
